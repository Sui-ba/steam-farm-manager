# Steam Farm Manager

Локальное приложение для учёта Steam-аккаунтов фермы. Интерфейс — веб-страница на твоём компьютере (стиль Apple, светлая и тёмная тема), без tkinter.

## Возможности
Боковая панель, светлая и тёмная тема. Приложение личное: без регистрации, подписок и кабинета.
- **Дашборд**: аккаунты, онлайн, фармят, сумма балансов, лента активности, метрики, сводка ASF
- **Аккаунты**: учёт, поиск, импорт и экспорт (Excel, TXT), вход через Chrome/Edge с кодом Guard, баланс и уровень, главный аккаунт ★
- **Боты ASF**: плитки со свечением по статусу, фильтр и поиск, выбор по одному, группой или всех, панель «Действия»
- **Действия**: пауза, продолжить, запуск, стоп, фарм часов, добавить игры, ключ или код, ник, приватность, баланс поинтов, инвентарь, передать главному, трейды, статус, 2FA; свои карточки с командами ASF
- **Прокси**: список, статистика, число аккаунтов на прокси, раздача 1:1 и запись `WebProxy` в конфиг бота ASF
- **Цикл**: ранг, опыт, дроп, доход, отправка на главный и реинвест
- **Прогрев**: чек-лист шагов по аккаунтам с прогрессом
- **Бейджи**: план ротации хостов для друзей (Community Leader): кто из аккаунтов идёт через какого хоста
- **Telegram**: бот для владельца и сотрудников. Токен от @BotFather, привязка по одноразовой ссылке, права (просмотр, баланс, управление, передача) и список доступных аккаунтов у каждого сотрудника; владелец получает уведомления о действиях сотрудников
- **Карточки**: проверка инвентаря и передача предметов главному аккаунту

## Запуск
```bash
pip install -r requirements.txt
python server.py
```
На Windows можно дважды кликнуть `start.bat`: откроется своё окно без вкладок. Закрытие окна останавливает программу.
Порт меняется переменной `SFM_PORT`; `--no-browser` — только сервер, без окна.

В Telegram у владельца и сотрудника с правом «Баланс» есть команды `/status`, `/balance` и `/cycle`. Кнопка «В конфиг ASF» на вкладке прокси записывает назначенный прокси в JSON бота и, если ASF запущен, делает `reload`.

Нужен Python 3.10+ и Google Chrome или Microsoft Edge (для входа в аккаунты). Selenium нужен только для кнопки входа.

## Пути
Кнопки «Пути» и «Папка ASF» принимают папку maFiles и папку с `ArchiSteamFarm.exe`. Они сохраняются в `settings.json`.

## Структура
| Файл | Назначение |
|---|---|
| `server.py` | сервер на стандартной библиотеке и JSON API |
| `web/` | интерфейс: `index.html`, `style.css`, `app.js` |
| `design/` | скриншоты и токены дизайна |
| `database.py` | SQLite |
| `exchange.py` | импорт и экспорт |
| `steam_guard.py` | коды Guard из maFile |
| `browser_login.py` | вход через Selenium |
| `asf_manager.py` | управление ASF и его IPC |

## Безопасность
- Сервер слушает только `127.0.0.1`, запросы с чужих Host и без служебного заголовка отклоняются.
- Пароли в `accounts.db` лежат открытым текстом. Не отправляй этот файл и экспорты другим людям.

## Вкладка ASF
- Боты показаны плитками: цвет и свечение зависят от того, что делает бот (фармит, онлайн, пауза, запускается, остановлен).
- Плитки выбираются по одной, «Выбрать все» выбирает всех. Кнопка «Действия» открывает заготовки: пауза, продолжить, запустить, остановить, статус, код 2FA.
- «Своя карточка» создаёт свою команду ASF. В команде `{bots}` — все выбранные боты через запятую, `{bot}` — команда отдельно для каждого. Карточки хранятся в `cards.json`.

## Ограничения
- Баланс, уровень, инвентарь и передача идут через ASF: аккаунт связан с ботом по логину (`SteamLogin`). Формат ответа ASF разбирается по шаблону; если уровень или баланс не подтянулись, проверь ответ в консоли и впиши значения вручную.
- Автокрафт значков не реализован: ASF крафтить значки не умеет.
- Список шагов «Прогрева» хранится в браузере (localStorage), отметки по аккаунтам в `accounts.db`.

## Свои карточки
В команде можно использовать `{bots}` (все выбранные через запятую), `{bot}` (команда отдельно для каждого) и `{ask:Вопрос}` (спросить значение при запуске). Пример: `play {bots} {ask:AppID}`. Карточки лежат в `cards.json`, лента активности в `activity.json`.

## Telegram
Токен и привязки хранятся в `telegram.json` (открытым текстом, не отправляй файл другим). В боте нет паролей, почт и maFiles: сотрудник видит статус, баланс, уровень и инвентарь, а управляет только паузой, продолжением, стартом, стопом и (по праву) передачей главному. Бот работает, пока запущен `server.py`, и нужен доступ в интернет.
