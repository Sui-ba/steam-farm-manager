# Steam Farm Manager

Программа для своих Steam-аккаунтов. Она открывается отдельным окном на твоём компьютере, это не сайт. Пароли, токен Telegram и прокси остаются только у тебя.

Через неё можно вести аккаунты и прокси, запускать уже установленный ArchiSteamFarm и подключить Telegram-бота для себя и сотрудников.

## Запуск

Нужны Windows и Python 3.10 или новее. Chrome не обязателен: для входа в аккаунт хватает Microsoft Edge, он уже есть в Windows.

### 1. Поставь Python

Скачай установщик с [python.org](https://www.python.org/downloads/windows/). В первом окне установщика включи **Add python.exe to PATH**, затем Install Now.

Проверка: нажми Win+R, напиши `cmd`, Enter, затем:

```bat
python --version
```

Должна появиться версия, например `Python 3.12.0`. Если написано, что команда не найдена, поставь Python ещё раз с этой галочкой и открой новое окно командной строки.

### 2. Открой папку программы

Если папка `steam_farm_manager` уже лежит на компьютере, этот шаг готов.

Если скачиваешь с GitHub: на странице репозитория нажми **Code → Download ZIP**, распакуй архив и открой папку, внутри которой лежат `start.bat` и `server.py`.

### 3. Поставь библиотеки

Это нужно один раз. В списке есть вход через браузер и шифрование паролей в базе. Само окно откроется и без этого шага, но вход в аккаунт и сохранённые пароли тогда не заработают.

В адресной строке проводника, находясь в папке программы, набери `cmd` и нажми Enter. В чёрном окне выполни:

```bat
python -m pip install -r requirements.txt
```

### 4. Запусти

Дважды щёлкни `start.bat`.

Откроется своё окно без вкладок и адресной строки. Закрыл окно — программа выключилась. Чтобы открыть снова, ещё раз запусти `start.bat`.

## Первое окно

В первый раз программа сама показывает форму. Файлы открывать и править не нужно. Любое поле можно оставить пустым и заполнить потом.

- **Папка ArchiSteamFarm.** Папка, внутри которой лежит файл `ArchiSteamFarm.exe`. Удобнее нажать «Обзор», чем копировать путь. ASF ставится отдельно: [страница загрузок](https://github.com/JustArchiNET/ArchiSteamFarm/releases). Если ботов пока нет, поле оставь пустым.
- **Папка maFiles.** Папка с файлами `.maFile` из Nebula или Steam Desktop Authenticator. Она нужна, чтобы при входе программа сама ввела код Steam Guard. Нет такой папки — оставь поле пустым.
- **Токен Telegram-бота.** Его даёт [@BotFather](https://t.me/BotFather) после команды `/newbot`. Без токена программа работает, просто не будет бота.
- **Telegram id владельца.** Число, которое присылает [@userinfobot](https://t.me/userinfobot). Это твой id, не id бота.
- **Имя владельца.** Как подписать тебя в меню бота. Можно написать своё имя.
- **Порт.** Это порт окна самой программы, не порт ASF. Оставь `8765`. Программа откроется по адресу `http://127.0.0.1:8765` только на этом компьютере. Другое число нужно, только если `8765` уже занят. После смены порта закрой окно и снова запусти `start.bat`.

Нажми **Сохранить и открыть**. Кнопка **Пропустить** тоже пускает внутрь: папки потом указываются кнопкой «Пути», бот — на вкладке Telegram.

## Что сделать дальше

1. На вкладке **Аккаунты** добавь аккаунт вручную или через **Импорт**. Для импорта есть готовые шаблоны, подойдут Excel и TXT.
2. На вкладке **Прокси** добавь прокси. **Раздать 1:1** назначает по одному прокси на аккаунт. **В конфиг ASF** записывает этот прокси боту.
3. На вкладке **ASF** кнопка **Запустить** включает ArchiSteamFarm. Логин аккаунта в программе должен совпадать с `SteamLogin` в конфиге бота, иначе баланс и уровень не найдутся.
4. Вкладка **Telegram** нужна, чтобы добавить сотрудников и выдать им ссылку. Сотрудник не получает пароли, почты и maFiles.

Пока окно открыто, владельцу в Telegram доступны команды `/status`, `/balance` и `/cycle`.

Цикл и отметки прогрева вводишь сам. Задачи прогрева ходят в ASF: часы в игре, которая уже есть на аккаунте, ник, приватность. Карточки читают очередь фарма из ASF. Бейджи ниже: свой план и чтение публичной страницы Steam. Крафт значка программа не нажимает.

## Если окно не открылось

Открой командную строку в папке программы (в адресной строке проводника набери `cmd`) и выполни:

```bat
python server.py
```

В этом окне будет текст ошибки.

- `python не является внутренней или внешней командой` — Python не установлен или не попал в PATH. Поставь его заново с галочкой **Add python.exe to PATH** и открой новую командную строку.
- `Уже запущено` — программа уже работает. Закрой её окно и запусти `start.bat` ещё раз.
- Порт занят — поставь в первом окне другой порт, например `8766`, либо открой файл `.env` и поменяй строку `SFM_PORT=8765`. Потом запусти `start.bat` снова.
- Боты ASF не видны — в папке должен лежать именно `ArchiSteamFarm.exe`. Логин аккаунта и `SteamLogin` бота пишутся одинаково.
- Кнопка входа молчит — ещё раз выполни `python -m pip install -r requirements.txt`. На компьютере должен быть Edge или Chrome.

## Как устроено окно

Программа слушает только `http://127.0.0.1:8765` (порт из `.env`, поле `SFM_PORT`). `start.bat` открывает это окно через Edge. Закрыл окно — сервер остановился. После обновления файлов запусти `start.bat` ещё раз.

Запросы окна к `/api` идут с токеном. Как он устроен, написано в разделе «Токен API».

## Mini App

Мини-приложение открывается внутри Telegram, с телефона. Это те же боты, что на компьютере. Кнопка в боте называется **Открыть панель**. Она появляется, только если в `.env` заполнен `MINIAPP_URL` и адрес начинается с `https://`.

Внизу четыре кнопки: Главная, Боты, Дропы, Профиль. Карточка аккаунта открывается из списка ботов.

- **Главная.** ASF запущен или нет, сколько ботов онлайн, сколько карт осталось, средний уровень, дропы и доход из учёта. Кнопки «Запустить всё» и «Остановить» есть у того, кому выдано управление. «Импорт из ASF» и сводка прокси видны владельцу.
- **Боты.** Список ботов, поиск и фильтры: все, фармят, онлайн, ошибка. Нажатие открывает карточку.
- **Аккаунт.** Логин, уровень, SteamID, прокси, есть ли maFile, настройки ASF, пауза и старт. Строка «Значки» — короткая сводка с последней проверки публичного профиля. Пароль виден только владельцу и по кнопке с глазом. У сотрудника написано «скрыт».
- **Дропы.** Сводка учёта за день: штуки и доход, которые внесены в программу. Неделя и месяц в учёте не разложены, там стоит заглушка.
- **Профиль.** Имя, роль, виден ли пароль, есть ли управление.

Цифры берутся с компьютера, где запущена программа. Чего нет в базе или в ASF, на экране стоит «—».

Mini App доказывает, кто пишет, подписью Telegram (`initData`). Токен окна ей не нужен и в страницу мини-приложения не подставляется.

## Туннель и вебхук

Бот ходит в Telegram сам, длинными запросами `getUpdates`, пока открыто окно программы. Вебхук включать не нужно. Если в @BotFather или через `setWebhook` уже указан адрес, опрос и вебхук мешают друг другу: удали вебхук, иначе команды бота замолчат. Отдельного приёма вебхука в программе нет.

Телефон не откроет `http://127.0.0.1`. Для кнопки «Открыть панель» нужен внешний адрес `https://`. Его даёт туннель: отдельная программа, которая смотрит в интернет и пересылает запросы на `http://127.0.0.1:8765`. Сама эта программа туннель не поднимает и не ставит.

Когда туннель уже работает:

1. В `.env` запиши `MINIAPP_URL=https://твой-адрес/miniapp/`
2. Закрой окно и снова запусти `start.bat`.
3. Напиши боту. В меню будет кнопка «Открыть панель».

Чужой адрес из `MINIAPP_URL` отдаёт только страницу `/miniapp` и запросы `/api/mini`. Список аккаунтов окна, пароли и остальной `/api` с этого адреса не открываются: они остаются на этом компьютере и требуют токен.

## Вкладка «Игры»

На вкладке **Игры** впиши публичное имя канала, например `@channel`, и нажми **Обновить**. Программа читает открытый предпросмотр `t.me/s` и оставляет только ссылки `store.steampowered.com/app/…` и `/sub/…`. Кнопка **Ещё посты** листает старше. Сама по таймеру ничего не качает.

Отметь игры и ботов ASF и подтверди добавление. Уйдёт команда `addlicense`. Steam примет пакет, только если он ещё отдаётся бесплатно. Сайты «как получить», ключи и пароли из постов не открываются и не сохраняются. Список лежит в `games.json` на этом компьютере и в git не попадает.

## Значки Steam

Вкладка **Бейджи** по-прежнему хранит твой план: название, уровень и карты вводишь сам. Крафт в Steam программа не нажимает.

Кнопка **Проверить Steam** читает публичную страницу значков. В аккаунте должен быть SteamID (17 цифр или короткое имя профиля), а сам профиль Steam — открытый. Результат виден на вкладке и строкой в Mini App. Примерно раз в полчаса проверка повторяется сама, первая — через минуту после старта.

Когда значок доходит примерно до 80% или до 100%, владельцу уходит сообщение в Telegram. Самый первый снимок молчит, чтобы старые значки не прислали пачку сообщений. Кэш лежит в `badge_live.json` и в git не попадает.

## Токен API

Запросы окна к `/api` требуют заголовок `Authorization: Bearer …`. Без токена или с чужим токеном ответ `401`.

При первом запуске программа создаёт токен, один раз печатает его в чёрном окне и сохраняет в `.api-token`. `start.bat` обычно запускает программу без чёрного окна, поэтому строку можно не ловить: окно подставляет токен само, из этого файла. Свой токен можно заранее записать в `.env` строкой `SFM_API_TOKEN`.

Mini App ходит в `/api/mini` по подписи Telegram, не по этому токену. Вебхук бота не используется. Пути `/api/telegram/webhook` и `/api/tg/webhook` оставлены без проверки токена, но обработчика на них нет.

Пароли, почты и данные прокси в `accounts.db` зашифрованы. Ключ лежит в `.sfm-key` (или в `SFM_SECRET_KEY`). Без этого файла база не читается. В списке аккаунтов пароль скрыт точками, кнопка «Показать» запрашивает его отдельно.

## Что нельзя никому отправлять

Не отправляй `.env`, `.api-token`, `.sfm-key`, `accounts.db`, `telegram.json` и экспорты аккаунтов. Эти файлы не попадают в git. В окне пароль по умолчанию закрыт точками.

Окно доступно только с этого компьютера. С телефона или другого ПК оно не откроется.
