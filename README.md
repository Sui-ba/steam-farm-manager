# Steam Farm Manager

Программа для своих Steam-аккаунтов. Она открывается отдельным окном на твоём компьютере, это не сайт. Пароли, токен Telegram и прокси остаются только у тебя.

Через неё можно вести аккаунты и прокси, запускать уже установленный ArchiSteamFarm и подключить Telegram-бота для себя и сотрудников.

## Запуск

Нужны Windows и Python 3.10 или новее. Chrome не обязателен: для входа в аккаунт хватает Microsoft Edge, он уже есть в Windows.

### 1. Поставь Python

Скачай установщик с [python.org](https://www.python.org/downloads/windows/). В первом окне установщика включи **Add python.exe to PATH**, затем Install Now.

Проверка: нажми Win+R, напиши `cmd`, Enter, затем:

```bat
python --version
```

Должна появиться версия, например `Python 3.12.0`. Если написано, что команда не найдена, поставь Python ещё раз с этой галочкой и открой новое окно командной строки.

### 2. Открой папку программы

Если папка `steam_farm_manager` уже лежит на компьютере, этот шаг готов.

Если скачиваешь с GitHub: на странице репозитория нажми **Code → Download ZIP**, распакуй архив и открой папку, внутри которой лежат `start.bat` и `server.py`.

### 3. Поставь библиотеку для входа через браузер

Это нужно один раз, для кнопки «Войти в браузере». Само окно программы откроется и без этого шага.

В адресной строке проводника, находясь в папке программы, набери `cmd` и нажми Enter. В чёрном окне выполни:

```bat
python -m pip install -r requirements.txt
```

### 4. Запусти

Дважды щёлкни `start.bat`.

Откроется своё окно без вкладок и адресной строки. Закрыл окно — программа выключилась. Чтобы открыть снова, ещё раз запусти `start.bat`.

## Первое окно

В первый раз программа сама показывает форму. Файлы открывать и править не нужно. Любое поле можно оставить пустым и заполнить потом.

- **Папка ArchiSteamFarm.** Папка, внутри которой лежит файл `ArchiSteamFarm.exe`. Удобнее нажать «Обзор», чем копировать путь. ASF ставится отдельно: [страница загрузок](https://github.com/JustArchiNET/ArchiSteamFarm/releases). Если ботов пока нет, поле оставь пустым.
- **Папка maFiles.** Папка с файлами `.maFile` из Nebula или Steam Desktop Authenticator. Она нужна, чтобы при входе программа сама ввела код Steam Guard. Нет такой папки — оставь поле пустым.
- **Токен Telegram-бота.** Его даёт [@BotFather](https://t.me/BotFather) после команды `/newbot`. Без токена программа работает, просто не будет бота.
- **Telegram id владельца.** Число, которое присылает [@userinfobot](https://t.me/userinfobot). Это твой id, не id бота.
- **Имя владельца.** Как подписать тебя в меню бота. Можно написать своё имя.
- **Порт.** Это порт окна самой программы, не порт ASF. Оставь `8765`. Программа откроется по адресу `http://127.0.0.1:8765` только на этом компьютере. Другое число нужно, только если `8765` уже занят. После смены порта закрой окно и снова запусти `start.bat`.

Нажми **Сохранить и открыть**. Кнопка **Пропустить** тоже пускает внутрь: папки потом указываются кнопкой «Пути», бот — на вкладке Telegram.

## Что сделать дальше

1. На вкладке **Аккаунты** добавь аккаунт вручную или через **Импорт**. Для импорта есть готовые шаблоны, подойдут Excel и TXT.
2. На вкладке **Прокси** добавь прокси. **Раздать 1:1** назначает по одному прокси на аккаунт. **В конфиг ASF** записывает этот прокси боту.
3. На вкладке **ASF** кнопка **Запустить** включает ArchiSteamFarm. Логин аккаунта в программе должен совпадать с `SteamLogin` в конфиге бота, иначе баланс и уровень не найдутся.
4. Вкладка **Telegram** нужна, чтобы добавить сотрудников и выдать им ссылку. Сотрудник не получает пароли, почты и maFiles.

Пока окно открыто, владельцу в Telegram доступны команды `/status`, `/balance` и `/cycle`.

Цикл, прогрев и бейджи — это твои пометки в программе. Сама она в игру не заходит и эти цифры из Steam не забирает.

## Если окно не открылось

Открой командную строку в папке программы (в адресной строке проводника набери `cmd`) и выполни:

```bat
python server.py
```

В этом окне будет текст ошибки.

- `python не является внутренней или внешней командой` — Python не установлен или не попал в PATH. Поставь его заново с галочкой **Add python.exe to PATH** и открой новую командную строку.
- `Уже запущено` — программа уже работает. Закрой её окно и запусти `start.bat` ещё раз.
- Порт занят — поставь в первом окне другой порт, например `8766`, либо открой файл `.env` и поменяй строку `SFM_PORT=8765`. Потом запусти `start.bat` снова.
- Боты ASF не видны — в папке должен лежать именно `ArchiSteamFarm.exe`. Логин аккаунта и `SteamLogin` бота пишутся одинаково.
- Кнопка входа молчит — ещё раз выполни `python -m pip install -r requirements.txt`. На компьютере должен быть Edge или Chrome.

## Что нельзя никому отправлять

Пароли лежат в `accounts.db` обычным текстом. Токен бота и пути лежат в `.env`. Сотрудники и приглашения лежат в `telegram.json`. Туда же относятся экспорты аккаунтов. Эти файлы не попадают в git. Не пересылай их и не выкладывай в чат.

Окно доступно только с этого компьютера. С телефона или другого ПК оно не откроется.
