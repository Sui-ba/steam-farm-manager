# Дизайн

- `screens/` — скриншоты всех экранов (Дашборд, Аккаунты, Прокси, ASF) в светлой и тёмной теме, 2x.
- `tokens.json` — цвета, радиусы, размеры, обои: всё, что нужно, чтобы пересобрать дизайн в Figma.

Файлы стиля лежат в `web/style.css` (переменные в `:root` и `:root[data-theme=dark]`).

## В Figma
1. Перетащи PNG из `screens/` в Figma как референс.
2. Для редактируемых слоёв: запусти `python server.py`, затем плагин html.to.design (Figma) и адрес `http://127.0.0.1:8765/` (плагин может не видеть localhost — тогда используй расширение плагина для Chrome).
3. Либо собери вручную по `tokens.json`.
